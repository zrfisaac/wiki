# Wiki conventions

- Keep pages concise: less is more.
- Write in Portuguese and save Markdown as UTF-8.
- Use Docsify links without `.md` extensions.
- Keep the wiki home index as a simple list of section links.
- Keep section `README.md` files as direct indexes; avoid breadcrumb or navigation menus inside pages.
- When creating a wiki section or page, add it to the relevant parent index/menu by default. Skip this only when the user explicitly asks not to add it.
- Keep wiki menu and index entries in alphabetical order by displayed name unless the user explicitly requests another order.
- Give each cultivation plant its own page. Keep the cultivation index as one alphabetical table with an emoji and concise estimates. Use a single midpoint value for harvest time and daily water there; put more precise ranges and conditions on each plant's page.
- Use the same titled sections on every plant page: harvest, water, resilience, care, nutrition, consumption, planting, storage, and propagation. Put a fitting emoji in each heading and add a short description under it.
- Use the same `Propagation` section for seed saving and for storing vegetative planting material such as cuttings, stems, or seedlings.
- In `Consumption`, describe how to eat or otherwise use the plant and its useful parts.
- Write compound plant names with spaces, not hyphens.
- Treat index values and resistance percentages as rough comparative estimates. Dedicated plant pages may give more precise ranges, such as an 8–12 month harvest window, with relevant variety, climate, and growth-stage details.
- Avoid redundant introductions, repeated links, and long explanations.

- In the cultivation index, include Nutrição and Micro columns rated Zero, Baixo, Médio, or Alto. Use Nutrição for overall food value and Micro for vitamins and minerals.
